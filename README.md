# Encanto na Mesa CBA - Landing Page

Landing page moderna, responsiva e de alta conversão para o serviço de locação e decoração de festas infantis **Encanto na Mesa** (@encantonamesacba) em Cuiabá - MT.

## 🚀 Tecnologias Utilizadas
- **HTML5 Semântico**
- **Tailwind CSS (CDN)**
- **Google Fonts (Fredoka & Quicksand)**
- **Font Awesome 6 (Ícones)**
- **JavaScript Vanilla** (Filtro interativo de temas)

## 🎈 Principais Funcionalidades
- **Hero Section:** Proposta de valor clara ("Faça do seu simples bolinho um verdadeiro Encanto na Mesa!") com CTA direto para WhatsApp.
- **Diferenciais Competitivos:** Destaque para balões 100% inflados no arco, facilidade de transporte no carro e retirada com antecedência.
- **Catálogo de Temas Interativo:** Filtro por categorias (*Meninas*, *Meninos*, *Especiais*) com fotos reais do acervo.
- **Espaço de Feedbacks:** Prova social humanizada baseada nos relatos reais das mamães no Instagram.
- **FAQ com Transparência:** Respostas humanizadas para quebras, avarias, prazos e conservação.
- **Conversão Ativa:** Botão flutuante e botões de chamada com mensagens pré-preenchidas direcionadas ao WhatsApp `(65) 99687-2050`.
